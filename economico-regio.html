📅 ¿Cuándo se realizará el sorteo?
El sorteo se realizará cuando se venda el último boleto. En ese momento se tomará como referencia el próximo Sorteo Mayor oficial de la Lotería Nacional que se celebre en martes.

Ejemplo: si el último boleto se vende un lunes, se utilizará el sorteo oficial del martes siguiente. Si se vende después de que ya se celebró el sorteo del martes, se tomará como referencia el siguiente martes oficial.
